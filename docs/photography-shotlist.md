# Photography shot list

Every photo on the site today is an AI render, standing in for real Rise Medical Hub photography while the hub finishes fit-out. Task 11 gave the renders a single shared grade in `src/app/globals.css` — a slight desaturation (`filter: saturate(.82) contrast(1.02)`) plus a navy multiply veil — so the five renders read as one consistent set instead of five separate AI sessions.

That grade lives at the CSS level, scoped to the frame classes (`.service-card-image`, `.detail-image`, `.page-hero-media`, `.gallery-item`, `.eecp-sticky-media`), not baked into any image file. When real photography replaces a render, nothing has to be re-exported: drop the new file in at the same path (or update the `image`/`src` reference in `src/content/site-data.ts` or `src/app/[slug]/page.tsx`) and it inherits the same grade automatically, so it still matches the rest of the set. If real photography starts looking better ungraded — well-lit, correctly white-balanced, already consistent — the grade is one shared rule to relax or remove, either globally (delete the block) or per shot (add an opt-out modifier class to that one frame instance and exclude it from the shared selector list). No per-image rework required either way.

The 12 shots below are the real shoot list. Five replace an existing AI render one-for-one; seven are net-new (things the renders never depicted, or generic renders that should become specific, on-location shots). Brief for the photographer: natural/window light over flash, calm and unhurried body language (no forced smiles at camera), and let the site's navy / mint / coral accents show up where they already exist in the space (signage, scrubs, upholstery, wayfinding) rather than adding props to match.

**Notes for the shoot**
- All frames on the live site crop to landscape or near-square aspect ratios except the EECP sticky panel (portrait, `.86 / 1`), which currently reuses shot 3. If a dedicated portrait EECP frame is wanted later, add a 13th shot; until then, shoot #3 loose enough to support a portrait crop.
- "Min. long edge 2400px" is a floor, not a target — shoot RAW at the camera's native resolution and downsample on export so future crops (hero, card, gallery) all still hit 2x-retina at their largest rendered size.
- Keep a consistent white balance/exposure approach across the whole shoot day so the set still reads as one family even before any grading is applied — the CSS veil should be a finishing touch, not a fix for mismatched raw captures.
